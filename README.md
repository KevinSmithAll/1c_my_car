## 📦 Скачать

Готовые сборки публикуются в разделе **[GitHub Releases](https://github.com/KevinSmithAll/1c_my_car/releases)**.

1. Откройте раздел Releases.
2. Выберите нужную версию.
3. Скачайте приложенный файл `.cf`.

Если в релизе пока нет файла `.cf`, готовая сборка ещё не опубликована.

## 🚀 Установка конфигурации

Файл `.cf` содержит конфигурацию 1С, но не является готовой информационной базой с пользовательскими данными.

1. Создайте новую тестовую информационную базу или сделайте резервную копию существующей.
2. Откройте базу в **Конфигураторе 1С**.
3. Выберите **Конфигурация → Загрузить конфигурацию из файла**.
4. Укажите скачанный файл `.cf`.
5. После загрузки обновите конфигурацию базы данных и проверьте запуск в режиме **1С:Предприятие**.

Названия пунктов меню могут немного отличаться в зависимости от версии платформы.

> ⚠️ Не загружайте конфигурацию поверх рабочей базы без резервной копии. Файл `.cf` не содержит данные информационной базы.
